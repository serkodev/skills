---
name: implement-ticket-and-commit
description: "Implement a piece of work based on a spec or set of tickets, and commit the changes."
---

Implement the work described by the user in the spec or tickets.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Once done, please review the work.

Commit your work to the current branch. If a ticket ID is available, include the corresponding ticket ID in the commit message.

If you implement multiple tickets in one go, create a separate commit for each ticket. Do not combine changes for multiple tickets into a single commit.
